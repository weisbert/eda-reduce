# 可选依赖 —— **这个文件不进打包流程**，package.py 不读它。
#
# 为什么单独放一个文件而不是写进 requirements.txt：
#   requirements.txt 是**被审计、被哈希、被冻进 lock** 的那一份。
#   往里加一行的代价是：重下轮子 + 过 glibc 审计闸 + 必须走 full 包
#   （增量包不带轮子，依赖哈希闸会挡住）。
#   下面这些东西缺了工具照样跑，不值得为它们把整条链拖下水，
#   也不值得让隔离区多背几 MB。
#
# 所以：这里列的东西**不会**被打进气隙包。想在隔离区用，
# 要么手工加进 requirements.txt 重出 full 包，要么让管理员上系统包。
